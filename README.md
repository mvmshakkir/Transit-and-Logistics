Transit and Logistics Management System
Overview

The Transit and Logistics Management System is a web-based platform designed to streamline transportation and logistics operations. It provides tools for managing trips, consignments, invoices, and fuel and freight records efficiently.

Key Features

-Trip Management: Added modules for vehicle-based trip entry and tracking.

-Consignment & Invoicing: Managed consignments, automated invoice generation, and improved data accuracy.

-Fuel & Freight Details: Integrated detailed records for fuel usage and freight expenses.

-Custom Reports: Developed user-specific reports using SQL and Stimulsoft Reports for real-time insights.

Technologies Used

Framework:  .NET Core

Language: C#

Database: SQL Server

Reporting Tool: Stimulsoft
